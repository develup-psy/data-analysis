# 구름모바일 분석 데이터

이 폴더는 현재 분석에 사용하는 원본형 업무 기록입니다. 주요 이용·청구·품질 기록은 2025년 1월부터 2026년 4월까지이며, 일부 후속 상담과 해지 설문 기록은 2026년 5월 초까지 이어집니다. 해지 라벨, 고정 분석 기준일, 표본가중치, 모델 분할 열은 없습니다. 분석자는 질문에 맞는 대상·기간·변수를 직접 정합니다.

- 고객 17,052명, 모바일 회선 18,000개. 고객 한 명이 여러 회선을 가질 수 있습니다.
- 회선의 가입일과 종료일은 `03_subscriptions.csv`에 있습니다. 빈 종료일은 자료 종료 시점까지 종료 기록이 없다는 뜻입니다.
- `03_subscriptions.csv`의 가입 유형은 신규·번호이동입니다. 가입 이후의 단말 변경·USIM 변경은 `08_device_events.csv`의 사건입니다.
- 월별 표는 회선·월당 한 행이며, 종료 후에는 행이 없습니다.
- `04_plan_history.csv`의 `request_case_id`가 있으면 요금제 변경에 앞선 문의 사건을 가리킵니다. 빈 값은 연결된 문의 기록이 없다는 뜻입니다.
- `11_support_cases.csv` → `12_support_contacts.csv` → `13_support_messages.csv`는 사건·접촉·발언의 서로 다른 단위입니다.
- `14_crm_actions.csv`의 `trigger`는 당시 접촉 대상으로 정한 운영상 이유이며, `related_case_id`가 있으면 앞선 문의 사건을 가리킵니다.
- `15_exit_reviews.csv`는 해지 후 기록이며 응답하지 않은 고객의 이유는 비어 있습니다.
- `student_data/`에는 이 폴더와 동일한 15개 CSV가 있습니다.

분석 순서와 실습 질문은 [프로젝트 진행안](../DATA_ANALYSIS_PROJECT_WORKFLOW.md)을 참고하세요.

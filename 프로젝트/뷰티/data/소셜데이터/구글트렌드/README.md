# 구글 트렌드 CSV 정리

사용자가 구글 트렌드 웹사이트에서 내려받은 CSV의 내용을 지표별로 정리했다. 검색 관심도는 2025·2026 조회의 주간 행을 한 파일로 합치고 개별 원본 2개를 삭제했다. 나머지 개별 원본 60개는 각 지표 폴더의 `원본/`에 보관한다. 기존 파일명과 SHA-256 기록은 `관리/구글트렌드_파일명변경목록.csv`에 있다.

## 폴더 구성

| 폴더 | 확인할 내용 | 개별 원본 |
|---|---|---:|
| `검색관심도/` | 8개 검색어의 주간 관심도 | 통합 파일만 보관 |
| `지역별관심도/` | 8개 검색어의 지역별 관심도 | 2개 |
| `연관검색어/` | 검색어와 함께 검색한 표현 | 28개 |
| `연관주제/` | 검색어와 연결된 주제 | 30개 |
| `관리/` | 원본 파일명 변경 내역 | — |

## 통합 파일

| 파일 | 내용 | 행수 |
|---|---|---:|
| `검색관심도/구글트렌드_검색관심도.csv` | 8개 검색어의 주별 관심도. `조회구분연도`로 두 조회를 구분 | 100 |
| `지역별관심도/구글트렌드_지역별관심도_2025-2026_조회별정규화.csv` | 8개 검색어의 16개 지역별 관심도, 조회별로 구분 | 32 |
| `연관검색어/구글트렌드_연관검색어.csv` | 검색어별 상위·급상승 연관 검색어 | 622 |
| `연관주제/구글트렌드_연관주제_2025-2026_통합.csv` | 검색어별 상위·급상승 연관 주제 | 630 |

검색어: 선크림, 피부장벽, 세럼, 립틴트, 두피케어, 스킨케어, 탈모샴푸, 비건화장품.

## 중요한 해석 기준

1. **2025·2026 검색관심도 지수는 서로 다른 조회에서 각각 정규화되었다.** 주별 통합본은 행을 한 파일로 모은 것이며, 두 조회의 값을 재조정하지 않았다. 중복 주인 `2025-12-28`도 두 조회에서 값이 달라 모두 보존했다. 따라서 조회 구분을 무시하고 하나의 연속 시계열로 연결하거나 2025와 2026의 지수 크기를 직접 비교하면 안 된다.
2. 지역별 관심도도 조회별 상대값이다. 서로 다른 조회 연도의 지역별 수치를 단순 증감률로 비교하지 않는다.
3. 연관 검색어·주제 원본 파일에는 **어떤 기준 검색어로 내보냈는지 적혀 있지 않다.** 통합본의 `기준검색어`는 파일 내용과 다운로드 순서로 매핑한 값이다.
4. 제공된 2025 조회 원본 중 비건화장품의 연관 검색어·주제 파일과 립틴트의 연관 검색어 파일은 찾지 못했다. 없는 조합은 통합본에 임의로 채우지 않았다.
5. `Breakout`은 원본의 증가율 표기 그대로 저장했다. 수치 비율로 변환하지 않았다. 연관 주제에는 무관한 자동 분류 결과가 포함될 수 있으므로 보고서 활용 전에 내용을 검토한다.
6. 원본 파일명에 2025 시작일과 2026-11-18 종료 표기가 함께 있으나, 주간 원본 행은 2025년 주차만 담고 있다. 따라서 `2025조회`는 제공된 파일 묶음을 가리키는 이름이며, 연관어 파일의 정확한 검색 설정 기간을 보증하지 않는다.
